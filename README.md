# HTML WEBSITE DEVELOPMENT ASSIGNMENT

## Question 1: Website Creation

I created a personal portfolio website for a Systems Engineering student. The website presents professional information including profile, competencies, industrial experience, academic background, and contact details.

The website demonstrates the use of more than 25 different HTML elements and more than 15 HTML attributes. It is structured using semantic HTML elements to ensure clarity and organization.

---

## Question 2: HTML Elements

### 1. Five Most Challenging Elements

- `<table>` – Required correct use of `<thead>`, `<tbody>`, `<tr>`, and `<td>`.
- `<form>` – Needed understanding of input validation and structure.
- `<fieldset>` – Learning how to group related form elements.
- `<select>` – Understanding how dropdown options work.
- `<address>` – Understanding its semantic purpose for contact information.

### 2. Use of Semantic Elements

- `<header>` contains the website introduction and navigation.
- `<nav>` provides structured internal links.
- `<main>` wraps the primary content of the website.
- `<section>` separates content into logical categories.
- `<article>` represents standalone content blocks.
- `<footer>` contains closing information and navigation.
- `<address>` is used for contact details.

### 3. Most Useful Element

The `<section>` element was most useful because it clearly divided the website into meaningful content blocks, improving readability and organization.

## Question 3: HTML Attributes

### 1. Three Essential Attributes

- `href` – Enables internal and external navigation.
- `type` – Defines input behavior in forms.
- `required` – Prevents incomplete form submission.

### 2. Difference Between class and id

The `id` attribute was used for unique sections such as "profile" and "contact".  
The `class` attribute was used to group similar elements such as multiple competency articles.

### 3. Attribute That Improved User Experience

The `placeholder` and `required` attributes significantly improved user experience by guiding users and ensuring form completeness.
